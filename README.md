# Open Data Examples

Example notebooks for datasets hosted on the [Registry of Open Data on AWS](https://registry.opendata.aws/).

| Dataset | Notebook |
|---|---|
| Downing Herbarium - Macquarie University | [Get to Know a Dataset](downing-herbarium-mq/get-to-know-a-dataset.ipynb) |

## Requirements

The notebooks need Python 3 and the libraries listed at the top of each notebook, e.g.:

```
pip install boto3 pandas matplotlib pillow
```

The data are in a public S3 bucket, so no AWS account or credentials are needed.
